What ParallelScope is

ParallelScope is a file browser that pulls folders from unrelated locations into a single tree. Register the folders you actually work in — say your active projects, your design assets, and your reports — and you can browse and search all of them from one window instead of juggling Explorer windows.

The folder structure and file listings are kept in a local SQLite cache. Listings are drawn from that cache first, so a folder opens instantly; the real file system is then re-read in the background to bring the listing up to date. That keeps the UI responsive even on slow locations such as a NAS over the network.

Every screenshot on this page was taken with dummy data placed under C:\ScopeDemo. It is not a real folder structure.

The main window

  1. Menu — opens the settings window.
  2. ← Back / Forward → / ↑ Up — move through your navigation history, or go to the parent folder.
  3. Address bar — the full path of the current folder. Type or paste a path and press Enter to jump there.
  4. Search box — searches under the current folder as you type (incremental search).
  5. All Files toggle — lists every file under the current folder as one flat list.
  6. Folder tree — your registered root folders, gathered under a top-level "Folders" node.
  7. File list — the contents of the selected folder. Click a column header to sort.

First run: add your root folders

After installation no roots are registered yet, and the app falls back to showing your Desktop. Start by registering the folders you want to browse.

  1. Open "Menu" → "⚙ Settings"
  2. On the "Root Folders" page, type the full path of a folder and click "Add"
    Roots appear in the tree in the order listed. Reorder them with "↑ Up" / "↓ Down", or drop one with "Remove".
  3. Optionally add folders to "Excluded Folders"
    Excluding noisy folders such as node_modules or bin keeps them out of the tree, the file list, search results, and scans.
  4. Click "Save + Full Scan"
    The cache is empty right after you add a root, so scanning once here makes browsing and searching fast from then on. Use "Save" if you only want to store the settings.

Exclusions are full paths, not name patterns. Adding a path excludes exactly that folder and everything under it — it does not exclude every folder that happens to share the name.

Browsing and navigating

  • Select in the tree — click a folder on the left and its immediate contents appear on the right. Click > to expand a node; children are loaded at that point.
  • Double-click — double-clicking a folder in the list moves into it; double-clicking a file opens it in the default application.
  • Back / Forward / Up — navigation history works the way it does in a browser.
  • Address bar — paste a path and press Enter to go straight there.
  • Sorting — click a column header such as "Name", "Size", or "Modified". Sizes and timestamps are compared as raw values rather than as displayed text, so 9 KB and 12 MB sort correctly.

The "Folders" node

The node at the very top of the tree is a virtual folder that gathers all your roots. It is not a real path, so selecting it shows ::Folders:: in the address bar and lists one row per root. Searching from here searches across every registered root at once.

Folder sizes

The size shown on a folder row is the total size of its contents, aggregated from the cache. Folders that have not been scanned yet show a blank size until a scan reaches them.

Searching

  • There is no search button. The list updates as you type.
  • The scope is everything under the folder you are currently viewing. To search everywhere, select the top-level "Folders" node first.
  • Search runs against the cache, never by walking the live file system, so it stays fast even on a NAS. The flip side: files added since the last scan are not found until the next one.
  • Clear the search box to return to the normal folder listing.
  • Excluded folders never appear in results.

All Files mode

Turning on "All Files" in the top right lists every file underneath the selected folder, recursively (folder rows are omitted). It is the fastest way to answer "I know it's in here somewhere".

  • This view is also built from the cache, so it reflects the most recent scan.
  • Selecting another folder while it is on switches the flat list to that folder.
  • Searching while it is on returns files only.
  • The on/off state is saved and restored the next time you start the app.

Scanning and the cache

Browsing and searching are built on the SQLite cache, which is refreshed in three ways.

  • Automatic full scan — once when the app starts, then on the interval you configure (3 hours by default). While it runs, an icon spins next to each root in the tree.
  • Save + Full Scan — saves your settings and immediately scans everything. Worth doing right after you add or change a root.
  • Per-folder scan — right-click a folder in the tree and choose "Scan everything under this folder". Much quicker than a full scan when only one area changed.

In addition, opening a folder re-reads its immediate contents from the live file system and updates both the listing and the cache. If a file you just added does not turn up in search, scan that folder or wait for the next automatic full scan.

The app stays usable while a scan runs. Triggering "Save + Full Scan" during a scan cancels the running one and restarts it with the new settings.

Customizing the view

Theme

Display columns (a ParallelScope Plus feature)

"Settings > Display Columns" chooses which columns the file list shows: Location (the parent folder path), Type, Size, Modified, Created, and Attributes. The Name column is always shown. Column customization is a paid Plus feature; without a subscription the list uses the default Name / Type / Size / Modified.

ParallelScope Plus (monthly subscription)

  • The Plus feature today is "Display Columns" (customizing the file list columns). Everything else is free.
  • Purchase, billing, and cancellation are handled entirely by the Microsoft Store. "Manage / Cancel subscription" opens the subscriptions page of your Microsoft account.
  • The subscription state is checked against your Microsoft Store license, so this only applies to the Microsoft Store build.

Where your data is stored

Settings and the cache are stored locally. Nothing is uploaded to any server.

FileContents
settings.jsonRoot folders, excluded folders, scan interval, theme, and other settings
ParallelScope.sqliteCached folder structure and file listings

In the Microsoft Store build they live in %LOCALAPPDATA%\Packages\msmsrep.ParallelScope_77t1an0ygyrva\LocalState. Uninstalling the app removes them as well.

Troubleshooting

A file I just added does not show up in search

Search reads the cache. Right-click that folder in the tree and run "Scan everything under this folder", or wait for the next automatic full scan.

A folder is missing from the tree

Check "Settings > Root Folders" and look at Excluded Folders — an excluded path and everything under it is hidden from the tree, the list, and search.

A NAS or network drive is slow or disconnected

Roots you cannot reach right now can still be browsed and searched from the cache. Once the connection is back, the next scan brings them up to date.

A folder shows no size

Folder totals are aggregated from scanned cache entries, so folders that have not been scanned yet show a blank size.

I want different columns

Adding or removing columns is a Plus feature. "Settings > Display Columns" links through to the subscription page.

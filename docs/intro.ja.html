ParallelScope

English日本語

離れた場所のフォルダも、
ひとつのツリーで。

ParallelScope は、ドライブやNASに散らばったフォルダをまとめて扱える Windows 向けファイルブラウザです。一度登録すれば、すべてを横断してブラウズ・検索でき、結果は打った瞬間に出てきます。

Microsoft Store で入手 使い方ガイドを読む

無料で使えます · Windows 10 / 11 · オープンソース

複数のルートを1つのツリーに

別々のドライブやNASにあるフォルダが、1つのツリーに並びます。

打った瞬間に検索

ローカルのキャッシュに対して検索するので、NASでも待たされません。

ネットワークが切れても見られる

つながらないルートも、キャッシュ済みの内容はそのまま閲覧・検索できます。

入力した瞬間にファイルが見つかる

検索欄に文字を打つたびに、現在のフォルダ配下が絞り込まれます。Enterキーも、ディスクを読み終えるのを待つ必要もありません。

起動時・定期・フォルダを開いたときのバックグラウンドスキャンで、キャッシュは常に最新に保たれます。

検索のしくみ →

深い階層も、1つの一覧に

All Files をオンにすると、現在のフォルダ配下のすべてのファイルを階層の深さに関係なく1つの一覧に並べます。フォルダの合計サイズも表示されるので、どこが容量を圧迫しているかすぐわかります。

All Files モードについて →

タブと2画面表示 Plus

複数のフォルダをタブで開いたまま行き来したり、画面を2つに分けて離れた場所のフォルダを見比べたりできます。タブはドラッグで反対側へ移せ、開いていた構成は次回起動時に復元されます。

タブと画面分割について →

右クリックですぐ操作

ファイル・ファイル名・フルパスをワンクリックでコピーしたり、親フォルダをエクスプローラーで開いたりできます。ツリーのフォルダを右クリックすれば、その配下だけをスキャンし直せます。

右クリックメニュー →

ライト／ダーク、日本語／英語

配色テーマと表示言語を選べます。どちらも選んだ瞬間に反映され、既定ではWindowsの設定に従います。

ファイルはあなたのPCの中だけで

処理はすべてローカルで行います。キャッシュと設定はアプリ専用のデータフォルダに保存され、外部へ送信されることはありません。ソースコードはすべて GitHub で公開しています。

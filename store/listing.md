## 日本語

### 製品名

Parallel Scope

### 概要

複数のNASやフォルダを横断して、大量のファイルを一瞬で検索・高速閲覧できるファイルビューアです。

### 説明

Parallel Scopeは、NASやPC内の大量のフォルダを“一瞬で検索・高速閲覧” できるファイルビューアです。
複数のNASやフォルダを横断して検索できるため、離れた場所にあるデータもまとめて素早く探し出せます。

主な機能

・NASでも高速検索（インクリメンタルサーチ）
バックグラウンドで自動スキャンしているため、文字を入力した瞬間に目的のファイルが見つかります。

・複数フォルダ・複数NASを横断検索
上位フォルダを選ぶだけで、離れた場所にあるフォルダや複数NASをまとめて検索できます。

・フォルダ容量がひと目でわかる
フォルダ内の総容量を一覧で確認でき、どこが容量を圧迫しているかすぐに把握できます。

・深い階層のファイルも一括表示（All Filesモード）
配下のすべてのファイルを1画面にまとめて表示。大量データの確認が圧倒的に楽になります。

・ネットワーク切れにも強いスマートスキャン
起動時・定期スキャン・フォルダオープン時に自動更新。
ネットワークが途切れても検索データが消えない堅牢設計です。

・直感的な操作と便利な右クリック
「戻る／進む／上へ」などの基本操作に加え、右クリックから
ファイル・ファイル名・フルパスをワンクリックでコピーできます。
ツリーの右クリックからは、そのフォルダ配下だけのスキャンも実行できます。

・画面に合わせて選べる配色と表示言語
配色テーマ（システム／ライト／ダーク）と表示言語（システム／英語／日本語）を切り替えられます。
どちらも選んだ瞬間に反映され、既定ではWindowsの設定に追従します。

・隠しファイル・システムファイルの表示切り替え
既定では表示します。チェックを外すと、ファイル一覧とフォルダツリーのどちらからも隠せます。

ParallelScope Plus（月額サブスクリプション）でできること

・複数タブ
フォルダを複数のタブで開いたまま行き来できます。タブごとに現在のフォルダ・戻る/進むの履歴・検索語・All Filesモード・並び順を持ち、
開いていたタブは次回起動時に復元されます。

・2画面（分割表示）
画面を左右または上下に分割し、離れた場所にある2つのフォルダを並べて見比べられます。
それぞれの側がフォルダツリーとファイル一覧を1組ずつ持ち、タブはドラッグで反対側へ移せます。

・ツリー最上位のショートカット
「★ お気に入り」「🕘 最近開いたフォルダ」「🕒 よく使うフォルダ」をツリーの最上位に表示します。
どれを表示するか、どの順番で並べるかも選べます。

・ファイル一覧の表示列のカスタマイズ
場所・種類・サイズ・更新日時・作成日時・属性から表示する列を選び、並び順と列幅を保存できます。

・表示中の一覧のCSV書き出し
検索結果やAll Filesモードの表示も、見えているとおりの並び・列でCSVへ書き出せます。
サイズは表示どおりの文字列と、集計しやすい生のバイト数のどちらかを選べます。

上記以外の機能は、サブスクリプションなしでお使いいただけます。

・一部の機能は、Microsoft Storeのアドオン「ParallelScope Plus」（月額サブスクリプション）として提供しています。

本アプリ（ParallelScope）は個人で開発・運営しています。
アドオンとは別に、継続的なアップデートや機能改善のため、任意の開発支援を受け付けています。
ご協力いただける場合は、アプリ内のリンクから支援していただけると大変励みになります。
（本サポートは対価のない任意の寄付であり、特典の提供はございません。）

## English

### Product name

Parallel Scope

### Short description

Search and browse huge folder trees across several NAS devices and folders at once.

### Description

Parallel Scope is a file viewer that searches and browses the huge folder trees on your NAS and PC in an instant.
Because it searches across several NAS devices and folders at once, files kept far apart are found together, quickly.

Key features

- Fast search, even on a NAS (incremental search)
Scanning happens in the background, so the file you want appears as you type.

- Search across several folders and several NAS devices
Pick a parent folder and folders in completely different places, on different NAS devices, are searched together.

- Folder sizes at a glance
The total size of each folder is right there in the list, so you can see what is eating your space.

- Files buried deep, all on one screen (All Files mode)
Every file under the current folder is listed flat on a single screen, which makes large data sets far easier to go through.

- Smart scanning that survives a dropped network
The cache is refreshed at startup, on a schedule, and whenever you open a folder.
Your search data is not lost when the network goes away.

- Straightforward navigation and a useful right-click menu
Back / Forward / Up, plus a right-click menu that copies the file, its name, or its full path in one click.
Right-clicking a folder in the tree scans just that folder and everything under it.

- A theme and a language to suit you
Switch the color theme (System / Light / Dark) and the display language (System / English / Japanese).
Both apply the moment you pick them, and both follow your Windows settings by default.

- Show or hide hidden and system items
They are shown by default; clear a checkbox to leave them out of both the file list and the folder tree.

What ParallelScope Plus (a monthly subscription) adds

- Multiple tabs
Keep several folders open and move between them. Each tab has its own folder, back/forward history, search text, All Files mode and sort order,
and your open tabs come back the next time you start the app.

- Split view
Split the window side by side or top and bottom to compare two folders that live far apart.
Each side has its own folder tree and file list, and tabs can be dragged from one side to the other.

- Shortcuts at the top of the tree
"★ Favorites", "🕘 Recent" and "🕒 Frequently Used" appear above your root folders.
You choose which of them to show, and in what order.

- A file list built the way you want it
Pick from Location, Type, Size, Modified, Created and Attributes, then keep your column order and widths.

- CSV export of the list you are looking at
Search results and All Files mode included, with the same rows, order and columns you see on screen.
Sizes can be written as displayed, or as raw byte counts for totalling in a spreadsheet.

Everything else is yours without a subscription.

- Some features are offered through "ParallelScope Plus", a monthly subscription add-on on the Microsoft Store.

ParallelScope is developed and run by one person.
Separately from the add-on, optional support toward continued updates and improvements is welcome.
If you would like to help, there is a link inside the app — it is a real encouragement.
(That support is a voluntary donation with nothing given in return, and no rewards attached.)
